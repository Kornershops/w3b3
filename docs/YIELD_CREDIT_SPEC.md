# Yield-Backed Credit: Spec & Implementation Status

## 1. Feature Overview

The **Yield-Backed Credit** module allows users to borrow stablecoins against their active staking positions without needing to unstake. This maximizes capital efficiency, similar to Aave or MakerDAO, but specifically utilizing yield-bearing assets as collateral.

## 2. Acceptance Criteria

- **AC1: Collateralization** ✅ — Users lock yield-bearing tokens (e.g., staked ETH receipts or W3B3 LP tokens) as collateral via `W3B3CreditLine.sol`.
- **AC2: Borrowing** ✅ — Users borrow stablecoins up to 50% LTV (`MAX_LTV = 5000` basis points).
- **AC3: Interest Accrual** ✅ — Loan accrues interest at 2% annual fixed rate (`INTEREST_RATE_BP = 200`) via `_accrueInterest`.
- **AC4: Yield Offset** ⚠️ — Spec'd but not implemented on-chain. The yield generated by locked collateral does not yet automatically offset borrow interest. Planned for Phase 15.
- **AC5: Liquidation** ✅ — Liquidation threshold at 60% LTV (`LIQUIDATION_THRESHOLD = 6000`). Liquidators receive a 5% bonus (`LIQUIDATION_PENALTY = 500`).
- **AC6: Dashboard (UI)** ⚠️ — Backend `CreditService` is complete (open, update, liquidate, health factor). Frontend "Borrow" tab in portfolio view is not yet built. Planned for Phase 15.

## 3. Architecture Components

1. **Smart Contract** ✅ — `W3B3CreditLine.sol` — deposit collateral, borrow, repay, withdraw collateral, liquidate, interest accrual.
2. **Backend** ✅ — `CreditService` + `CreditPosition` Prisma model — full CRUD for credit positions.
3. **Frontend** ❌ — "Borrow" tab in portfolio view not yet built.

## 4. Oracle Status

The contract currently uses a `uint256 collateralPriceAsset` mock price set by the owner via `setMockPrice()`. Phase-14 adds Chainlink round completeness and timestamp staleness guards. Full live Chainlink feed integration is targeted for Phase 15 (post phase-14 merge).
